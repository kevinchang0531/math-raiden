# 數學雷電

雷電風格的直向飛機射擊遊戲，武器升級要先答對 20 以內的加減題。給國小低年級練習計算用。

**▶ 線上玩：https://kevinchang0531.github.io/math-raiden/**（第一次載入約 40 MB，請稍等）

## 怎麼玩
- 開始畫面選遊戲難度：簡單／普通／困難（題目都是 20 以內加減，難度只影響敵人和扣血）
- 方向鍵或 WASD 移動，也可以按住滑鼠拖曳（手機可用手指拖曳）；自動射擊；X 放炸彈；P 暫停；Shift 慢速；M 靜音
- 手機／平板：按住畫面拖曳移動、右下「炸彈」鈕
- 打下運輸機會掉道具，道具每 2 秒換顏色：
  - 和目前武器同色 → 四選一計算題，答對就升級（按 1～4 或點選）
  - 不同色 → 直接換武器
- 打敵機收集零件（機翼、發動機、外觀、升降輪），到「工廠」研發匿蹤型／終極型戰機、強化機體、輔助飛機
- 第 10 關起開放「情報機構」：派特工收集情報，超過 50% 可削弱敵人 3 分鐘
- 開始畫面按 H 看道具說明
- 遊戲中右上「離開」鈕（或 Q）可結束這一局回開始畫面
- 有血條：被打到扣血，血扣光才掉一條命；每答對一題補 20 血
- 結算畫面會列出答錯的題目，方便複習
- 暫停：P／Esc 或右上「暫停」按鈕；切到別的分頁會自動暫停
- 線上排行榜：遊戲結束輸入暱稱（最多 8 字，**請不要用真實姓名**），顯示全部玩家前 10 名與自己的名次；標題畫面按 L 查看
